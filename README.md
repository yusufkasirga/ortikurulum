# Orti

Oyun arkadaşı bulma uygulaması — Expo (React Native), Android + iOS.

## Çalıştırma
- `npm install`
- `npx expo start` → telefonda Expo Go ile QR kodu okut

## APK
- Bulut: `npx eas-cli@latest build -p android --profile preview` (Expo hesabı gerekir)
- GitHub: `main` dalına her push'ta Actions sekmesinde `orti-apk` olarak çıkar
